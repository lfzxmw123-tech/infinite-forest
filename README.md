# INFINITE FOREST · 无尽之森

Three.js + TypeScript + Vite 的实时程序化森林。所有树木、叶片、树皮、地形和水体都由代码生成，没有图片背景或视频，也不需要外部 3D 资产。

## 启动

```sh
npm install
npm run dev -- --port 5173
```

打开 http://localhost:5173/ 。使用支持 WebGPU 或 WebGL2 的现代浏览器。默认优先 WebGPU，Three.js 自动回退 WebGL2；也可打开 http://localhost:5173/?webgl 强制 WebGL2。

点击「走进森林」锁定鼠标。WASD 移动、鼠标环顾、Shift 加速、Space 跳跃、Esc 暂停释放鼠标。右上角可选择时刻、风力、画质、昼夜自然流逝。自动漫游从首页「自动漫游」入口开启，进入后可在底部控制栏调整速度、暂停或切换手动探索。触屏设备可拖动画面环顾，按住左下角箭头前进。

## 已实现

- 固定世界种子 271828，连续多尺度噪声地形、河谷和蜿蜒溪流。
- 40 米区块，普通 5×5 / 高画质 7×7；每帧最多填充一个新区块，离开的区块复用，活动数量有上限。
- 三种巨树原型，树干、分枝、板根和带透明叶片的树冠；树木、草簇、蕨类、苔石均批量实例绘制。
- 高度加权的局部树枝/树叶/草风动；树根固定，各树风频率与相位变化。TSL 同时生成 WGSL 与 GLSL。
- 近景完整树木，远景简化树干与树冠；远景不绘制草、蕨与植被投影；视锥剔除。
- 昼夜太阳/环境光、动态树影、指数距离雾、低空漂移雾片、穿林光束、萤火虫、尘埃和落叶。
- 水面着色器波纹、沿岸石块与植被。
- 第一人称移动、加速、跳跃、地面/树干碰撞、步态起伏、触屏控制、可选合成环境音。

## 验证

```sh
npm test       # 种子稳定性、地形边界与法线、跨 1 km 区块回收、碰撞、LOD、WGSL/GLSL 生成
npm run build  # 严格 TypeScript 检查与生产构建
npm run test:browser  # 需本机允许启动 Playwright Chromium；先保持开发服务运行
```

浏览器测试可通过 `CHROMIUM_PATH` 指定已安装的测试版 Chromium。否则使用 Playwright 默认浏览器（必要时先执行 `npx playwright install chromium`）。测试覆盖页面启动、进入/鼠标锁定、键盘移动、环顾、跳跃、昼夜切换、时钟与粒子更新、跨区块生成/回收、画质切换和窄屏布局，并把截图保存到 `artifacts/`。

本开发环境已通过逻辑测试与两后端的 Three.js 着色器代码生成检查。浏览器控制服务不可用，测试 Chromium 进程被系统沙箱拒绝，因此尚未完成 GPU 画面与实际交互验收，也没有虚报帧率或电影级画质。

## 技术范围

这是自包含的程序化森林实现。光束与地雾采用透明几何近似，并非光线追踪体积散射；溪流使用动态表面着色，并非流体模拟。没有外部扫描植被、PBR 摄影测量资产或 UE5 级路径追踪。阴影采用相机附近的局部阴影贴图。无限指持续流式生成且没有预设地图边界，极端天文距离仍受浮点精度限制。

源码入口 `src/main.ts`，世界生成位于 `src/forest/`，环境效果位于 `src/effects/`，移动控制位于 `src/controls/`。

## TRAIN MODE · 森林列车

首页点击「森林列车」进入，默认静止。按 **R** 启动，**W / S** 持续增加或减少牵引，**Space** 紧急制动，**H** 鸣笛，**V** 切换视角，**E** 停车下车。也可直接点击火车控制面板。下车后点击「继续探索」恢复鼠标锁定，靠近车头按 E 可再次上车。

- 一台蒸汽机车和三节有座椅、车窗的客车，带车轮、连杆、烟囱、车灯和驾驶室。当前为程序化模型，没有下载外部 GLB；`src/train/TrainModel.ts` 是后续替换真实资产的位置。
- 驾驶室、前侧车窗、第三人称三个视角，1.8 秒平滑过渡；悬挂震动不会传给相机。
- 每段 32 米的 Catmull-Rom 中央曲线，共用相邻控制点，位置和切线连续；轮转用实际运行距离，车体分别采样轨道并跟随切线。
- 固定 9 个活动铁路区块，钢轨、枕木、道床、桥墩、桥栏实例化并复用；曲线缓存最多 32 段，蒸汽最多 72 个粒子。
- 首次上车才启用铁路走廊，对附近地形、草木和岩石做必要避让；河床保留，桥墩连接地面与桥面。既有森林和动物继续运行，列车/鸣笛使附近动物警觉并向轨道外逃离。
- 程序化石拱隧道提供渐暗过渡，夜晚和隧道内使用车头聚光灯。桥隧与内饰是程序化近似，没有真实山体地质、流体或铁路运营模拟。
- 右上角总声音开关同时控制列车音效。浏览器仍可能需要一次点击才允许播放。

```sh
npm run test:train          # 4 km 回收、曲线接缝、物理、镜头、真实 HTML 控件与上下车生命周期
npm run test:train:browser  # 需要允许启动 Playwright 浏览器，并保持 localhost:5173 开发服务运行
```

本环境已执行列车逻辑和 DOM 集成测试；浏览器控制服务不可用，尚未进行真实 GPU 画面、键鼠手感与帧率验收。WGSL/GLSL 检查验证着色器代码生成，不等同于 GPU 驱动编译或实测性能。
